# Agent instructions — EMA hourly continuation

1. Read `README.md` and this file before substantial work.
2. Historical research only. Never place orders or deploy live/paper trading. Use only free public data and no-cost tooling.
3. Preserve the documented EMA signal, fill logic and cost assumptions unless a new, versioned experiment explicitly changes them. Never describe fixtures as market evidence.
4. Apply the adaptive research-gate policy in the README. For a blocked historical-universe gate, a separate, explicitly labeled current-universe exploratory benchmark may be used to measure implementation and baseline behavior; never call a current rank snapshot point-in-time historical truth or use it as confirmation.
5. Keep a strict confirmatory run separate from exploratory pilots. Do not silently reduce frozen history, sample, execution or cost requirements; a relaxed version must get a new ID and report survivorship, selection, uncertainty and cost sensitivity.
6. Preserve all negative and blocked results. Do not select a winner on the final holdout or claim profitability without auditable net-of-cost results, data provenance and independent checks.
7. After three materially distinct attempts across two independent data/source approaches fail the same feasibility gate—or when a documented structural limit makes the gate unattainable—stop repeating the same failure and complete the next bounded, no-cost exploratory or source-independent task.
8. Never modify unrelated projects or trigger paid services. Inspect diffs and retain a clear research handoff with exact evidence and one measurable next task.
